# おえかきジャンプ v3

GitHub Pagesで公開できる静的Webアプリです。子どもの絵を背景透過PNGへ仕上げ、ブラウザ内で動くGIFを作成します。

## v3の主な変更

- 参考イメージに合わせ、黄色を基調にピンク・ブルー・ミント・ラベンダーを使ったモダンでポップなUIへ刷新
- 設定画面で生成プロンプトを複数管理
  - 追加
  - 複製
  - 削除
  - 名前変更
  - 本文編集
  - 使用プロンプトの切替
- 動きプロンプトを管理
  - 動きプリセットの追加・複製・削除
  - 表示名、アイコン、アニメーションタイプ、プロンプトを編集
  - 選択した動きプロンプトは画像生成時の追加指示へ反映
- 動きプリセットの変更はメイン画面へ自動反映

## 動きプロンプトについて

GIFの移動・回転・伸縮そのものはブラウザ内のアニメーションエンジンで作ります。
「動きプロンプト」は、生成するイラストが選択した動きに適した余白・重心・構図になるよう、画像生成APIへ追加指示として渡されます。

カスタム動きを追加する際は、次のアニメーションタイプから1つ選びます。

- ジャンプ
- 左右ゆれ
- ふわふわ
- くるくる
- ぷるぷる
- 伸び縮み

## GitHub Pages 公開方法

1. ZIPを展開して、中身をGitHubリポジトリの直下へアップロード
2. GitHubで `Settings` → `Pages`
3. `Build and deployment`
4. `Source` → `Deploy from a branch`
5. Branch → `main`
6. Folder → `/ (root)`
7. `Save`

## カメラについて

カメラ直接起動にはHTTPSが必要です。GitHub PagesはHTTPSで配信されます。直接カメラを起動できないブラウザでは、端末標準のカメラ選択画面へフォールバックします。

## APIキーについて

利用者が設定画面で自分のAPIキーを入力する方式です。GitHubリポジトリのHTML/JavaScriptにはAPIキーを入れません。

- 「この端末にAPIキーを保存する」ON: localStorageへ保存
- OFF: sessionStorageのみ

公開WebアプリでAPIキーを扱う方式は、サーバー側で秘密情報として管理する構成より安全性は低くなります。

## 外部ライブラリ

GIF作成には `gif.js.optimized 1.0.1` を使用し、jsDelivr CDNから読み込みます。GIF変換自体はブラウザ内で行います。

## manifest の読み込みについて

この版では互換性を高めるため、メインのWeb App Manifestを `manifest.json` に変更しています。
この配布版では転送互換性を優先し、Manifest は `manifest.json` のみ同梱しています。

**重要:** `index.html` をPC上で直接ダブルクリックして `file://` で開くと、ブラウザによってはManifestやService Workerが `Failed to fetch` になります。
GitHub Pagesなどの **HTTPS** 配信で開くか、ローカル確認ではHTTPサーバー経由で開いてください。

例:
```bash
python3 -m http.server 8000
```
その後 `http://localhost:8000/` を開きます。
## v4 画面デザイン

トップ画面は提供された参考イメージを元に、背景画像として貼り付けるのではなくHTML/CSS/インラインSVGで再構築しています。カメラ、画像選択、動き選択、生成、保存などの操作は従来どおり実際に機能します。

設定画面では複数の生成プロンプトと、追加・修整可能な動きプロンプトを管理できます。
